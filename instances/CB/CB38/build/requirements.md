Build from the official `nginx:1.25.5` image. The base layer supplies a minimal Nginx configuration, the source-shaped static-file tree, and curl for real HTTP assertions. The instance layer restricts the root-owned static directory and selects the unprivileged `nginx` worker user, producing the permission-denied response. The only repairable configuration file is `/etc/nginx/nginx.conf`; the repair changes its `user` directive so the configured worker can read the static tree. The container uses the source image's normal Nginx entrypoint and remains available for investigation through Docker exec.
