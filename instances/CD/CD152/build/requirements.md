Use the clean official `apache/hadoop:3.3.6` image. Preserve its Hadoop installation and runtime. The instance layer must change only `/opt/hadoop/etc/hadoop/core-site.xml`, setting `fs.defaultFS` to an invalid remote endpoint so the real HDFS client reports a connection-refused failure. Keep the container alive for the harness and fixer shell; do not copy benchmark metadata or harness files into the image. No build command script is required because the fault overlay is self-contained.
