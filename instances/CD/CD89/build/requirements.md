Use `ubuntu:22.04` as the clean source image. Install the Ubuntu OpenJDK development runtime and the packaged Apache Log4j 2.17.1 API/core libraries. Compile the small real Log4j2 caller in the base layer. The base configuration must suppress logger additivity; the fault overlay replaces only that configuration with the source configuration, where the child logger inherits additivity and shares the root appender. Do not copy benchmark metadata or harnesses into the image.
